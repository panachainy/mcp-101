# MCP-101

## Create new project

| Type                   | Command                                            |
| ---------------------- | -------------------------------------------------- |
| New Golang App         | `bun nx generate @nx-go/nx-go:app apps/<app-name>` |
| New TypeScript App     | `bun nx g @nx/js:app apps/<app-name>`              |
| New TypeScript Library | `bun nx g @nx/js:lib packages/<lib-name>`          |
