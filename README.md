# MCP-101

## Create new project

| Type                   | Command                                                           |
| ---------------------- | ----------------------------------------------------------------- |
| New Golang App         | `bun nx generate @nx-go/nx-go:app apps/<app-name>`                |
| New TypeScript App     | `bun nx g @nx/js:app apps/<app-name>`                             |
| New TypeScript Library | `bun nx g @nx/js:lib packages/<lib-name>`                         |
| New Python Flask App   | `bun nx g @nx-python/nx-python:app apps/sqlite --template flask`  |
| New Python Django App  | `bun nx g @nx-python/nx-python:app apps/sqlite --template django` |
| New Python App         | `bun nx generate @nxlv/python:poetry-project apps/<app-name>`     |
